1肺炎随伴性胸水・肺膿瘍・膿胸

鉄則1片側胸水に対して胸腔穿刺を行い、感染が原因かそれ以外の胸水か判断する
鉄則2感染性胸水とわかったらドレナージを試みよう
鉄則3感染性胸水の機序を推測し起因菌を考えることで、適切な抗菌薬が選択できる

鉄則1　胸腔穿刺で感染かどうかを判断する

  • 性状、細胞数・分画、生化学、微生物学的検査、細胞診またはセルブロックで系統的に分析する。
  • 価値：診断的（鑑別の絞り込み・原因の確定）、予測的（ドレナージへの反応）、予後的（悪性胸水の再発・進行）

Lightの基準（1つ以上で滲出性）

  • 胸水総蛋白／血清総蛋白＞0.5
  • 胸水LDH／血清LDH＞0.6
  • 胸水LDH＞血清LDH基準値上限の2/3
漏出性胸水滲出性胸水
機序静水圧の上昇と膠質浸透圧の低下－
主な原因心不全、肝硬変、ネフローゼ症候群、低アルブミン血症感染性胸水、結核性胸膜炎、悪性腫瘍、肺塞栓症など
左右両側性が多い－
対応まずは薬物治療が多い胸腔穿刺で診断をつける

鉄則3　機序から起因菌を推定する

表1-2　感染性胸水の機序と初期治療
機序想定する起因菌初期治療
口腔内の微生物が肺膿瘍を形成し、胸腔へ穿破／誤嚥口腔内常在菌：緑色レンサ球菌、Fusobacterium sp.、Prevotella sp.、Actinomyces sp.、HACEKアンピシリン・スルバクタム
胸部の外傷・胸腔穿刺・心臓手術などの医療処置MRSA、緑膿菌セフェピム＋バンコマイシン
腹腔内膿瘍が横隔膜から胸腔内に波及大腸菌、Bacteroides sp.などの嫌気性菌セフトリアキソン＋メトロニダゾール（院内感染ならCTRX→セフェピムなど）
潜在性結核の活性化（結核性胸膜炎）結核菌多剤併用療法（RFP、EB、INH、PZAなど。裏面）

起因菌の頻度（表1-1）

  • 市中：緑色レンサ球菌（〜32%）、S. anginosus group（4〜24%）、肺炎球菌（10〜22%）、MSSA（10〜19%）、嫌気性菌（6〜20%）
  • 院内：黄色ブドウ球菌（MRSA含む、〜38%）、グラム陰性桿菌（8〜17%）

肺膿瘍と有瘻性膿胸

  • 原因：口腔内不衛生、嚥下機能低下に伴う誤嚥、扁平上皮がんによる気管支の閉塞
  • 穿破すると有瘻性膿胸→ 感染コントロールに難渋。気管支鏡で瘻孔充填が必要 → 呼吸器内科にコンサルト

結核性胸膜炎の診断

  • 胸水培養の感度は低い。胸腔鏡で組織採取（白色結節が多い）
  • 培養陰性でも結核は否定できない → 胸膜生検を考慮

2肺結核

鉄則1治療反応性に乏しい肺炎や、2週間以上持続する発熱・体重減少・夜間盗汗を伴う咳嗽で結核を疑う。ホームレス、収監者、HIV感染者の肺炎では必ず疑う
鉄則2結核を疑った場合には、患者の陰圧室への収容と、3連痰を提出しよう
鉄則3抗結核薬は副作用が多い。INHの末梢神経障害、RFPの消化器症状と皮疹、EBの視神経炎、PZAの高尿酸血症をモニターしよう

鉄則1　結核を疑う場面

疫学

  • 2021年に人口10万対9.2で低蔓延国に。ただし先進国では高い（2024年：日本8.1、ドイツ5.4、米国3.2、韓国35、フィリピン625）
  • 大阪府が最も高い（12.8）
  • 新規は高齢者（特に70歳以上）に多く、外国出身者の割合も増加 → 高齢者、流行国の出身者・渡航後の肺炎では結核を鑑別に

疑う症状・状況

  • 発熱、体重減少、夜間盗汗、血痰を伴う2週間以上の咳嗽
  • 通常の市中肺炎の治療に反応しない
  • 無症状でも気道散布性粒状影・空洞影（上の2つとともに、特にリスクが高い患者で疑う）
  • CTで気道散布性の小葉中心性粒状影 → 強く疑う

鉄則2　陰圧室と3連痰

　結核は空気感染（飛沫核感染）

陰圧隔離

  • 診察は陰圧室。患者は室外でサージカルマスク、医療者はN95マスク
  • 塗抹陽性・PCR陽性は排菌あり → 排菌がなくなるまで陰圧室。難しければ指定病院へ
  • 空洞影・喉頭結核も排菌ありとして対応

3連痰

  • 3日間連続で喀痰塗抹検査
  • 早朝痰を含む8〜24時間おきに採取
  • 1回でも陽性なら排菌あり
  • 結核菌PCRと抗酸菌培養も併せて行う

発生届

  • 感染症法の二類感染症
  • 診断したら最寄りの保健所に直ちに届出
  • 治療は公費負担 → 申請も行う

鉄則3　治療と副作用のモニター

  • 原則：①3剤以上併用 ②確実な服薬確認 ③副作用の早期発見
  • 1剤での治療は禁忌。結核が疑われる肺炎にフルオロキノロン（LVFXなど）は避ける
  • 培養に2〜6週間 → 耐性リスクがなければINH・RFP・EB・PZAの4剤で開始

維持期を7か月に延長する状況（表2-4）

  • PZAが使えない（特に80歳以上）／広範な空洞影／粟粒結核／2か月後も培養陽性／免疫抑制剤・HIV／再治療例
  • 中枢神経結核：2025年版では通常6か月・4か月レジメンの対象外（2016年版：髄膜炎は計9〜12か月）
  • 治療終了後も再燃をフォローアップ
  • IDSA/ATS更新：感受性結核の4か月短縮レジメン、耐性結核のBPaL/BPaLM 6か月全経口。本邦未承認薬あり、適格性を慎重に判断

副作用（対処は表2-5）

  • 肝障害（INH・RFP・PZA）：症状ありは上限の3倍、なしは5倍まで経過観察。超えたら被疑薬を中止し1剤ずつ再開
  • INH：末梢神経障害（ボタンが掛けられない）→ ビタミンB6を併用
  • RFP：嘔気 → 休薬し少量から再開して漸増。皮疹、血球減少
  • RFP：CYP3A4・CYP2C19の強力誘導薬（アムロジピン、プレドニゾロン、抗不整脈薬などの濃度低下）→ 開始前に常用薬を確認
  • EB：視神経炎 → ベースライン＋定期的な眼科診察
  • PZA：高尿酸血症・痛風 → 尿酸降下薬。肝障害
  • RBT：ぶどう膜炎（眼底検査）、筋肉痛・関節痛
  • 継続困難ならsecond line（LVFXなど）

もっと知りたい：潜在性結核・T-SPOT

  • T-SPOT陽性＝過去に結核に出会ったか。画像・症状がなければ潜在性結核
  • 治療対象：進展リスクが高く、有益性が副作用を上回る患者（移植、血液腫瘍、免疫抑制剤、HIV、透析、直近曝露の医療者など）
  • 6H（INH 6〜9か月）、4R（RFP 4か月）、3HR（3か月）。INHはマグロ・鰹・チーズで中毒症状 → 食事指導
  • 開始前に活動性結核を必ず除外
  • 偽陽性：M. marinum、M. kansasii、M. szulgai
疑ったら陰圧室・N95・3連痰・保健所へ届出。治療は4剤2か月＋2剤4か月。単剤治療は禁忌で、副作用は薬剤ごとにモニターする。
