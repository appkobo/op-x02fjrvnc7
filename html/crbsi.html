1診断・感染経路・起因菌

鉄則1CRBSIは臨床診断や研究を目的とし、CLABSIは感染管理やサーベイランスを目的とする基準である
鉄則2CRBSIは皮膚からの直接侵入、カテーテルハブの感染、血行性波及、汚染された注射製剤の4つの経路で発生する
鉄則3CRBSIではグラム陽性球菌が主な起因菌であるが、近年ではグラム陰性菌やカンジダの関与が増加している
鉄則4CRBSIの治療期間は複雑性の有無と起因菌の2つの軸で考える

鉄則1　CRBSIとCLABSIの違い

  • 日本の問題：CVCからの血液培養が採られない、末梢血とCVCのどちらから採ったかのラベル付けが徹底されない → CRBSIが見過ごされる

血液培養の採り方

  • 血液培養は必須の検査
  • 末梢血で2セット、または原因カテーテルから1セットと末梢血で1セット
  • 末梢血2セットで、原因菌として矛盾しない同一の菌が検出されても診断できる
  • 強く疑う場合は原因カテーテルから1セット（2時間早く陽性になり同じ菌が培養されることが診断基準の1つ）
  • 抜去したカテーテル先端のグラム染色・培養は初期抗菌薬の参考になるが、抜去時に汚染されうる → 必ず血液培養も採取

疑うきっかけ

  • 菌血症を疑う悪寒戦慄があるのに感染巣がはっきりしない → 疑って血液培養
  • CNSやコリネバクテリウムなど病原性の低い細菌では、刺入部の感染徴候が目立たないことも多い
疑ったら末梢血とカテーテルから同時に血液培養を採り、どちらから採ったかを必ず書く。

鉄則2　4つの感染経路

感染経路内容
①皮膚からの直接侵入皮膚の常在菌が挿入部位から侵入（内因性：患者自身の皮膚常在菌、外因性：医療従事者の汚染された手指）→ 手指衛生と挿入部位の消毒
②カテーテルハブの感染接続部のハブが汚染され（皮膚常在菌、医療従事者の手指）、内腔を通って血流感染
③血行性波及別の感染部位から血流を介してCVCに付着 → 他に感染源がないかを常に念頭に
④汚染された輸液・注射製剤極めて稀（例：輸液にカリウムを混注する際の手技による汚染）
図1　4つの感染経路
CVC周辺の身体所見と、他の感染源となる遠隔病巣がないかを注意深く観察する。

鉄則3　起因菌

CLABSIの起因菌（米国）

  • CDC/NHSN 2011〜2014年：CNS 16%、黄色ブドウ球菌 15%、腸球菌 13%、クレブシエラ 8%、大腸菌 5%、エンテロバクター 4%
  • ICU 2017年：カンジダ 27%、腸球菌 17%、腸内細菌科細菌 16%。一般床でもカンジダ・腸内細菌科細菌が増加

部位と患者背景から推定

  • 最多はCNS（MSS、MRS）。次いで黄色ブドウ球菌（MSSA、MRSA）、コリネバクテリウム、バチルス（皮膚、リネン類など病院環境）
  • 鼠径部のライン → 腸球菌、腸内細菌科細菌（陰部の常在菌。オムツをしていなくても存在）
  • 水回りの緑膿菌などブドウ糖非発酵菌も稀に

カンジダを保菌するリスク

  • 抗菌薬前投与歴、糖尿病、免疫抑制剤使用歴、移植後
  • 消化管手術またはその他の大手術、ICU入室歴
  • 中心静脈栄養中、低栄養状態
グラム陽性球菌を最上位に考えつつ、グラム陰性桿菌とカンジダも常に考慮する。

2治療期間とカテーテル抜去

鉄則4　治療期間は「複雑性の有無」と「起因菌」で決める

  • 留置期間が短期（14日以内）と長期（14日以上）で異なるが、大きくは複雑性の有無と起因菌で決まる
  • 複雑性（血行性に播種）：①化膿性血栓性静脈炎、②感染性心内膜炎、③骨髄炎、④遠隔播種性病変
治療期間
非複雑性：CNS10〜14日間（短期留置カテーテルは5〜7日間）
非複雑性：腸球菌・GNR7〜14日間
複雑性：感染性心内膜炎4〜6週間
複雑性：骨髄炎6〜8週間

黄色ブドウ球菌・カンジダ

黄色ブドウ球菌

  • 複雑性に関係なくカテーテルの抜去が基本。抜去後はリスクに応じて4〜6週間
  • ①免疫不全なし ②人工物なし ③感染性心内膜炎なし ④持続的な菌血症・発熱なし ⑤播種性病変なし、をすべて満たす低リスクは2週間を検討

カンジダ

  • カテーテルの抜去とエキノキャンディン系薬剤の併用で死亡率が低下
  • 血液培養が陰性となった後に2週間。眼内炎や遠隔播種性病変があれば延長
📘 黄色ブドウ球菌菌血症（IDSA/ESCMID 2026）
  • 「複雑性／非複雑性」→ 低リスク／高リスクに層別化
  • 低リスク（フォローの血液培養＋経胸壁心エコーでリスク因子・病巣なし）→ 14日間
  • 主なリスク因子：市中発症、48時間以上後の血液培養陽性、心臓内デバイス
  • 高リスクでも病巣がなく改善すれば14日間。菌血症が長引く・評価が不十分なら延長を考慮
  • 期間は血液培養が陰性化した日から数える。経胸壁心エコーは成人全例。CVCは速やかに抜去

カテーテルを抜去すべき5つの条件

  • ①血行動態的に不安定
  • ②重度Sepsis（旧SIRS criteria）
  • ③化膿性血栓性静脈炎によるカテーテル周囲の発赤や滲出液
  • ④複雑性CRBSI（血栓性静脈炎、感染性心内膜炎、骨髄炎、感染性塞栓症などの合併）
  • ⑤72時間以上の適切な抗菌薬治療にもかかわらず菌血症が持続

→ 迅速にカテーテルを抜去する

カテーテル抜去が原則となる場合

  • バイタルサインが不安定、刺入部に顕著な感染徴候、CNS以外が原因菌（黄色ブドウ球菌・カンジダは抜去が必須）、菌血症が持続
  • CNSは抜去せずに治療する場合もある
  • 緑膿菌も抜去が原則で抜去後5〜7日。やむを得ず抜去できなければ10〜14日
  • 新しいカテーテルにも原因菌が再付着しうる → 入れ替えが容易な末梢静脈から挿入することが多い（困難なら中心静脈）

要注意の病態や合併症

  • 感染性心内膜炎、化膿性血栓性静脈炎

3抗菌薬・予防・ロック療法

初期治療と原因菌ごとの抗菌薬・治療期間

基本

  • 最多のCNSやGPCを対象にVCM

バイタルが不安定・好中球減少

  • VCMに加えて、緑膿菌やカンジダを考慮しCAZやMCFGの併用を考慮
  • 血圧低下など：VCM＋CAZ（またはCFPM）

バイタルが不安定かつカンジダ合併の危険性が高い

  • さらにMCFGの併用を考慮
  • 治療期間は原因菌、カテーテル抜去の有無、合併症の有無で変わる。CNSでCVポートなど容易に抜去できなければVCM 2週間

もっと知りたい：CLABSIの予防

  • チェックリスト
  • カテーテル挿入用カートまたはキット
  • 手指衛生
  • 最大限の無菌バリア予防策
  • アルコールを含むクロルヘキシジンによる皮膚消毒
  • 鎖骨下静脈を挿入部位に選択（集中治療室の患者の場合）
  • クロルヘキシジン含有ドレッシング
  • クロルヘキシジンを用いた入浴
  • 抗菌薬または消毒薬でコーティングされたカテーテル
  • カテーテル挿入前のハブおよびキャップの手動消毒
  • 消毒薬を含むハブおよびキャップ

もっと知りたい：抗菌薬ロック療法（ALT）

  • 透析カテーテルやCVポートなど入れ替えがすぐにできない、挿入が困難な場合に、CVCを抜去せずに治療を継続する方法。EDTA、ミノサイクリン、エタノールを使う
  • 注目すべきはバイオフィルムへの透過性：バンコマイシン・リネゾリドは透過性が悪い、ダプトマイシン・ミノサイクリン・トリメトプリムは良好
  • フィブリン形成を阻害する抗凝固薬で透過性が増す。EDTAはヘパリンより良好
  • EDTAはGPC・GNRに、エタノールはさらにカンジダや緑膿菌にも効果
